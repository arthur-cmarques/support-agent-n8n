# KB-02 — Pedido marcado como entregue, mas não recebido

> Documento FICTÍCIO criado para fins de portfólio. Não representa políticas reais de nenhuma empresa.

- O agente nunca resolve este caso sozinho.
- O caso é encaminhado para verificação humana (localização da entrega e contato com o entregador).
- O cliente deve ser informado de que a verificação é feita por uma pessoa da equipe.
