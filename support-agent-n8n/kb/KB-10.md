# KB-10 — Cupons: regras de uso e devolução

> Documento FICTÍCIO criado para fins de portfólio. Não representa políticas reais de nenhuma empresa.

- Só é possível usar um cupom por pedido; cupons não acumulam.
- Se o pedido é cancelado antes do preparo, o cupom volta automaticamente para a conta do cliente.
- Cupom usado em pedido entregue não é devolvido.
